# conda-pycosat-solver

The `pycosat` solver used in `conda`, also available as `classic`.

## What is this exactly?

conda-pycosat-solver provides the `pycosat`-based SAT solver that has been powering `conda`'s
resolution process since its inception, historically known as the `classic` solver (`classic`
remains available as an alias). It's now packaged separately to benefit from the configurability
of the plugin system.

## Documentation

Check the [documentation](https://conda.github.io/conda-pycosat-solver/) for
instructions on how to install, use and make the most out of the `pycosat` conda solver!
